# Sharp_-_MZ-700

Thumbnails for Sharp MZ-700 software, laid out as [libretro-thumbnails](https://github.com/libretro-thumbnails) (`Named_Snaps`), named after the MAME short names, as the MAME `mz700_cass` software list has them.

The snaps were taken with the MAME libretro core in RetroArch: a Lua autoboot script starts the tape and types `L`, each cassette is run for 12000 frames, and the last frame is kept, at the machine's own resolution scaled 2x. Without a player the games stay on their title or instructions screen, which is what the snaps show. Software the list says to load from BASIC, and titles that showed only the monitor or a blank screen, have no snap.
